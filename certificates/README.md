# Certificates and supporting documents

This folder is for certificates and professional evidence that Artwell has chosen to make public on the portfolio.

## Add a certificate

1. Sign in to GitHub using the account that owns this repository.
2. Open this folder and choose **Add file → Upload files**.
3. Upload a PDF or image with a clear filename, for example `excel-certificate-2026.pdf`.
4. Commit the upload to the `main` branch.
5. Add a View or Download link for the uploaded file in the Certificates section of `index.html`.

## Before publishing

- Remove or cover student numbers, national ID numbers, home addresses, signatures, QR codes or other private details that do not need to be public.
- Only publish documents you own or have permission to share.
- Do not upload original identity documents or unredacted academic records.
- Everything in this folder is public because this is a public repository. Do not put private documents here.
